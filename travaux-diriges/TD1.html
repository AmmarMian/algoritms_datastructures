Préambule : Utilisation de Linux

Dans ce cours, nous allons programmer en C sous Linux. Pour cela, nous utiliserons principalement le terminal (Konsole sous Fedora), qui nous permet de compiler et exécuter nos programmes. Cette section vous familiarisera avec les commandes essentielles.

1. Découvrir le terminal

Le terminal est une interface texte qui permet d'interagir avec le système d'exploitation. Sous Fedora, ouvrez l'application Konsole. Vous verrez quelque chose comme :

╔══════════════════════════════════════════════════╗
║ 📟 Konsole                         ─  □  ✕       ║
╠══════════════════════════════════════════════════╣
║                                                  ║
║  [user@fedora ~]$ █                              ║
║                                                  ║
╚══════════════════════════════════════════════════╝

Le symbole [user@fedora ~]$ est appelé le prompt. Il indique que le terminal attend une commande. Le ~ représente votre répertoire personnel (home).

2. Les commandes essentielles

2.1. Se repérer : pwd et ls

pwd (Print Working Directory) affiche le chemin du répertoire courant :

╔══════════════════════════════════════════════════╗
║  [user@fedora ~]$ pwd                            ║
║  /home/user                                      ║
║  [user@fedora ~]$ █                              ║
╚══════════════════════════════════════════════════╝

ls (LiSt) liste les fichiers et dossiers du répertoire courant :

╔══════════════════════════════════════════════════╗
║  [user@fedora ~]$ ls                             ║
║  Bureau  Documents  Images  Téléchargements      ║
║  [user@fedora ~]$ █                              ║
╚══════════════════════════════════════════════════╝

Options utiles : ls -l (format détaillé), ls -a (fichiers cachés inclus).

2.2. Se déplacer : cd

cd (Change Directory) permet de changer de répertoire :

╔══════════════════════════════════════════════════╗
║  [user@fedora ~]$ cd Documents                   ║
║  [user@fedora Documents]$ pwd                    ║
║  /home/user/Documents                            ║
║  [user@fedora Documents]$ █                      ║
╚══════════════════════════════════════════════════╝

Raccourcis utiles :

  • cd ~ ou simplement cd : retour au répertoire personnel
  • cd .. : remonter d'un niveau
  • cd - : revenir au répertoire précédent

2.3. Créer : mkdir et touch

mkdir (MaKe DIRectory) crée un nouveau dossier :

╔══════════════════════════════════════════════════╗
║  [user@fedora ~]$ mkdir test_linux               ║
║  [user@fedora ~]$ ls                             ║
║  Bureau  Documents  test_linux  Téléchargements  ║
║  [user@fedora ~]$ █                              ║
╚══════════════════════════════════════════════════╝

Pour créer une arborescence complète : mkdir -p dossier1/dossier2/dossier3

touch crée un fichier vide :

╔══════════════════════════════════════════════════╗
║  [user@fedora test_linux]$ touch fichier.txt    ║
║  [user@fedora test_linux]$ ls                    ║
║  fichier.txt                                     ║
║  [user@fedora test_linux]$ █                     ║
╚══════════════════════════════════════════════════╝

2.4. Manipuler : cp, mv, rm

cp (CoPy) copie un fichier : cp source.txt copie.txt

mv (MoVe) déplace ou renomme un fichier : mv ancien.txt nouveau.txt

rm (ReMove) supprime un fichier : rm fichier.txt

Attention : La suppression avec rm est définitive ! Pour supprimer un dossier et son contenu : rm -r nom_dossier

2.5. Afficher et nettoyer : cat et clear

cat affiche le contenu d'un fichier :

╔══════════════════════════════════════════════════╗
║  [user@fedora ~]$ cat test.txt                   ║
║  Bonjour, ceci est un fichier texte !           ║
║  [user@fedora ~]$ █                              ║
╚══════════════════════════════════════════════════╝

clear nettoie l'écran du terminal (raccourci : Ctrl+L).

3. Éditer des fichiers texte

Pour écrire du code C, vous devez éditer des fichiers. Vous avez plusieurs options :

Option 1 : VS Code (recommandé)

À la faculté, utilisez VS Code (Visual Studio Code) qui est installé sur toutes les machines. Sur votre ordinateur personnel, vous pouvez utiliser gedit (Linux/GNOME) ou Kate (Linux/KDE), mais nous recommandons VS Code pour sa cohérence avec l'environnement de la fac (voir le guide d'installation).

Pour utiliser VS Code :

  • Lancez VS Code depuis le menu d'applications ou tapez code dans le terminal
  • Ouvrez votre dossier de travail : File → Open Folder ou code . depuis le terminal
  • Créez un nouveau fichier : File → New File, puis sauvegardez-le avec l'extension .c
  • Utilisez le terminal intégré : Ctrl+` pour compiler et exécuter

Important : VS Code est utilisé uniquement comme éditeur de texte. Nous compilerons TOUJOURS manuellement dans le terminal avec la commande gcc. N'utilisez pas les fonctionnalités de compilation automatique de VS Code. Le but de ce cours est de comprendre le processus de compilation, pas de l'automatiser.

Option 2 : nano (simple et guidé)

nano est un éditeur de texte simple dans le terminal. Les commandes sont affichées en bas de l'écran :

╔══════════════════════════════════════════════════╗
║  GNU nano 7.2              test.c                ║
╠══════════════════════════════════════════════════╣
║                                                  ║
║  #include <stdio.h>                              ║
║                                                  ║
║  int main(){                                     ║
║      printf("Hello World\n");                    ║
║      return 0;                                   ║
║  }                                               ║
║                                                  ║
╠══════════════════════════════════════════════════╣
║ ^G Aide   ^O Écrire  ^W Chercher  ^K Couper     ║
║ ^X Quitter ^R Lire   ^\ Remplacer ^U Coller     ║
╚══════════════════════════════════════════════════╝

Commandes essentielles (le symbole ^ signifie Ctrl) :

  • Ouvrir un fichier : nano nomfichier.c
  • Sauvegarder : Ctrl+O puis Entrée
  • Quitter : Ctrl+X

Option 3 : vi/vim (pour les plus aventureux)

vi est un éditeur puissant mais avec une courbe d'apprentissage plus raide. Il fonctionne avec des modes :

  • Mode normal : déplacement et commandes (mode par défaut)
  • Mode insertion : écriture de texte (touche i)
  • Mode commande : commandes avancées (touche :)

Commandes de survie :

  • Ouvrir : vi nomfichier.c
  • Passer en mode insertion : i
  • Sortir du mode insertion : Échap
  • Sauvegarder et quitter : :wq puis Entrée
  • Quitter sans sauvegarder : :q! puis Entrée

Notre recommandation : Utilisez VS Code pour profiter d'une interface graphique moderne avec coloration syntaxique et autocomplétion. Si vous préférez travailler entièrement dans le terminal, nano est parfait pour débuter. Une fois à l'aise avec Linux, vous pourrez explorer vim qui est très puissant pour l'édition de code.

5. Introduction à la compilation avec gcc

gcc (GNU Compiler Collection) est le compilateur C que nous utiliserons. Il transforme votre code source (.c) en programme exécutable.

5.1. Premier test avec un programme minimal

Dans le dossier INFO501/TD1, créez un fichier test.c :

nano test.c

Écrivez ce programme minimal :

int main(){
    return 0;
}

Sauvegardez (Ctrl+O) et quittez (Ctrl+X).

5.2. Compiler et exécuter

Compilez votre programme :

╔══════════════════════════════════════════════════╗
║  [user@fedora TD1]$ gcc test.c                   ║
║  [user@fedora TD1]$ ls                           ║
║  a.out  test.c                                   ║
║  [user@fedora TD1]$ █                            ║
╚══════════════════════════════════════════════════╝

Par défaut, gcc crée un fichier exécutable nommé a.out. Pour l'exécuter :

╔══════════════════════════════════════════════════╗
║  [user@fedora TD1]$ ./a.out                      ║
║  [user@fedora TD1]$ echo $?                      ║
║  0                                                ║
║  [user@fedora TD1]$ █                            ║
╚══════════════════════════════════════════════════╝

Le ./ signifie "dans le répertoire courant". La commande echo $? affiche le code de retour du programme (ici 0, ce qui signifie succès).

5.3. Donner un nom à l'exécutable

Pour donner un nom spécifique à votre programme, utilisez l'option -o :

╔══════════════════════════════════════════════════╗
║  [user@fedora TD1]$ gcc test.c -o mon_programme  ║
║  [user@fedora TD1]$ ls                           ║
║  mon_programme  test.c                           ║
║  [user@fedora TD1]$ ./mon_programme              ║
║  [user@fedora TD1]$ █                            ║
╚══════════════════════════════════════════════════╝

Exercice 2 : Des sommes et des produits

2.1 - Somme des \(n\) premiers entiers

On souhaite écrire un programme qui calcule la somme des \(n\) premiers entiers: $$ \sum_{i=1}^{n} i = 1 + 2 + 3 + \ldots + n. $$ Pour effectuer un calcul itératif de cette somme, supposons que nous ayons calculé la somme des \(n−1\) Premiers entiers et que nous ayons placé le résultat dans une variable resultat. On a alors que la somme des \(n\) premiers entiers est la somme des \(n−1\) premiers entiers plus \(n\).: $$ \underbrace{\sum_{i=1}^{n} i}_{\mathrm{resultat}} = \underbrace{\sum_{i=1}^{n-1} i}_{\mathrm{resultat}} + n $$ Ecrire un programme qui demande à l'utilisateur de rentrer un entier \(n\) et qui affiche la somme des \(n\) premiers entiers. On utilisera une boucle for pour effectuer la somme.

Aide

D'après la description, le pseudo-code serait le suivant:

resultat <- 0
pour i allant de 1 à n faire:
    resultat <- resultat + i

2.2 - Somme des carrés des \(n\) premiers entiers

On souhaite maintenant écrire un programme qui calcule la somme des carrés des \(n\) premiers entiers: $$ \sum_{i=1}^{n} i^2 = 1^2 + 2^2 + 3^2 + \ldots + n^2. $$

Écrire un programme qui demande à l'utilisateur de rentrer un entier \(n\) et qui affiche la somme des carrés des \(n\) premiers entiers. On utilisera une boucle for pour effectuer la somme.

Testez votre programme avec \(n = 5\) : vous devriez obtenir \(1 + 4 + 9 + 16 + 25 = 55\).

2.3 - Somme jusqu'à dépasser un seuil

On souhaite maintenant résoudre le problème suivant : étant donné un seuil \(S\), trouver le plus petit entier \(k\) tel que la somme des \(k\) premiers entiers dépasse \(S\).

Mathématiquement, on cherche le plus petit \(k\) tel que : $$ \sum_{i=1}^{k} i > S $$

Par exemple, si \(S = 100\), on cherche le plus petit \(k\) tel que \(1 + 2 + 3 + \ldots + k > 100\).

Écrire un programme qui :

  1. Demande à l'utilisateur de rentrer un seuil \(S\)
  2. Calcule la somme des entiers en incrémentant \(k\) jusqu'à ce que la somme dépasse \(S\)
  3. Affiche la valeur de \(k\) trouvée et la somme obtenue

Testez votre programme avec \(S = 100\) : vous devriez trouver \(k = 14\) car \(1 + 2 + \ldots + 14 = 105 > 100\) mais \(1 + 2 + \ldots + 13 = 91 \leq 100\).

Aide

Utilisez une boucle while qui continue tant que la somme est inférieure ou égale au seuil :

somme <- 0
k <- 0
tant que somme <= S faire:
    k <- k + 1
    somme <- somme + k

Exercice 3 : Suite de Syracuse (BONUS)

Exercice bonus : Cet exercice est plus difficile et nécessite de combiner plusieurs concepts vus précédemment. Il est facultatif mais fortement recommandé pour approfondir votre maîtrise du langage C.

Contexte : La conjecture de Collatz

La suite de Syracuse, aussi appelée conjecture de Collatz, est l'un des problèmes non résolus les plus célèbres des mathématiques. Bien que très simple à énoncer, personne n'a encore réussi à prouver ou réfuter cette conjecture depuis qu'elle a été formulée en 1937.

La suite est définie de la manière suivante : partant d'un entier positif \(u_0\), on construit la suite \((u_n)\) selon la règle :

$$ u_{n+1} = \begin{cases} \dfrac{u_n}{2} & \text{si } u_n \text{ est pair} \\[0.5em] 3u_n + 1 & \text{si } u_n \text{ est impair} \end{cases} $$

La suite s'arrête lorsqu'on atteint la valeur 1. La conjecture de Collatz affirme que, quel que soit l'entier positif de départ \(u_0\), la suite finit toujours par atteindre 1.

Exemple avec \(u_0 = 13\) :

13 → 40 → 20 → 10 → 5 → 16 → 8 → 4 → 2 → 1

Définitions

  • Temps de vol : C'est le nombre d'étapes nécessaires pour atteindre 1 à partir de \(u_0\). Dans l'exemple ci-dessus avec \(u_0 = 13\), le temps de vol est 9.
  • Altitude maximale : C'est la valeur maximale atteinte par la suite. Dans l'exemple avec \(u_0 = 13\), l'altitude maximale est 40.

Travail à réaliser

Écrire un programme en C qui étudie la suite de Syracuse pour un entier \(u_0\) donné par l'utilisateur.

3.1 - Affichage de la suite complète

Écrire un programme qui demande à l'utilisateur de rentrer un entier \(u_0\) et qui affiche toute la suite de Syracuse jusqu'à atteindre 1.

Vous devez créer une fonction int syracuse_suivant(int u) qui prend un terme de la suite et retourne le terme suivant selon la règle de Syracuse.

Exemple de sortie pour \(u_0 = 13\) :

Entrez un entier positif : 13
Suite de Syracuse :
13 40 20 10 5 16 8 4 2 1

3.2 - Calcul du temps de vol

Modifier votre programme pour qu'il calcule et affiche le temps de vol (nombre d'étapes pour atteindre 1).

Créez une fonction int temps_vol(int u0) qui prend la valeur initiale et retourne le temps de vol.

Exemple de sortie pour \(u_0 = 13\) :

Entrez un entier positif : 13
Suite de Syracuse :
13 40 20 10 5 16 8 4 2 1
Temps de vol : 9

3.3 - Calcul de l'altitude maximale

Modifier votre programme pour qu'il calcule et affiche l'altitude maximale atteinte par la suite.

Créez une fonction int altitude_max(int u0) qui prend la valeur initiale et retourne l'altitude maximale atteinte.

Exemple de sortie pour \(u_0 = 13\) :

Entrez un entier positif : 13
Suite de Syracuse :
13 40 20 10 5 16 8 4 2 1
Temps de vol : 9
Altitude maximale : 40
