Préambule : Utilisation de Linux

Dans ce cours, nous allons programmer en C sous Linux. Pour cela, nous utiliserons principalement le terminal (Konsole sous Fedora), qui nous permet de compiler et exécuter nos programmes. Cette section vous familiarisera avec les commandes essentielles.

1. Découvrir le terminal

Le terminal est une interface texte qui permet d'interagir avec le système d'exploitation. Sous Fedora, ouvrez l'application Konsole. Vous verrez quelque chose comme :

╔══════════════════════════════════════════════════╗
║ 📟 Konsole                         ─  □  ✕       ║
╠══════════════════════════════════════════════════╣
║                                                  ║
║  [user@fedora ~]$ █                              ║
║                                                  ║
╚══════════════════════════════════════════════════╝

Le symbole [user@fedora ~]$ est appelé le prompt. Il indique que le terminal attend une commande. Le ~ représente votre répertoire personnel (home).

2. Les commandes essentielles

2.1. Se repérer : pwd et ls

pwd (Print Working Directory) affiche le chemin du répertoire courant :

╔══════════════════════════════════════════════════╗
║  [user@fedora ~]$ pwd                            ║
║  /home/user                                      ║
║  [user@fedora ~]$ █                              ║
╚══════════════════════════════════════════════════╝

ls (LiSt) liste les fichiers et dossiers du répertoire courant :

╔══════════════════════════════════════════════════╗
║  [user@fedora ~]$ ls                             ║
║  Bureau  Documents  Images  Téléchargements      ║
║  [user@fedora ~]$ █                              ║
╚══════════════════════════════════════════════════╝

Options utiles : ls -l (format détaillé), ls -a (fichiers cachés inclus).

2.2. Se déplacer : cd

cd (Change Directory) permet de changer de répertoire :

╔══════════════════════════════════════════════════╗
║  [user@fedora ~]$ cd Documents                   ║
║  [user@fedora Documents]$ pwd                    ║
║  /home/user/Documents                            ║
║  [user@fedora Documents]$ █                      ║
╚══════════════════════════════════════════════════╝

Raccourcis utiles :

  • cd ~ ou simplement cd : retour au répertoire personnel
  • cd .. : remonter d'un niveau
  • cd - : revenir au répertoire précédent

2.3. Créer : mkdir et touch

mkdir (MaKe DIRectory) crée un nouveau dossier :

╔══════════════════════════════════════════════════╗
║  [user@fedora ~]$ mkdir test_linux               ║
║  [user@fedora ~]$ ls                             ║
║  Bureau  Documents  test_linux  Téléchargements  ║
║  [user@fedora ~]$ █                              ║
╚══════════════════════════════════════════════════╝

Pour créer une arborescence complète : mkdir -p dossier1/dossier2/dossier3

touch crée un fichier vide :

╔══════════════════════════════════════════════════╗
║  [user@fedora test_linux]$ touch fichier.txt    ║
║  [user@fedora test_linux]$ ls                    ║
║  fichier.txt                                     ║
║  [user@fedora test_linux]$ █                     ║
╚══════════════════════════════════════════════════╝

2.4. Manipuler : cp, mv, rm

cp (CoPy) copie un fichier : cp source.txt copie.txt

mv (MoVe) déplace ou renomme un fichier : mv ancien.txt nouveau.txt

rm (ReMove) supprime un fichier : rm fichier.txt

Attention : La suppression avec rm est définitive ! Pour supprimer un dossier et son contenu : rm -r nom_dossier

2.5. Afficher et nettoyer : cat et clear

cat affiche le contenu d'un fichier :

╔══════════════════════════════════════════════════╗
║  [user@fedora ~]$ cat test.txt                   ║
║  Bonjour, ceci est un fichier texte !           ║
║  [user@fedora ~]$ █                              ║
╚══════════════════════════════════════════════════╝

clear nettoie l'écran du terminal (raccourci : Ctrl+L).

3. Éditer des fichiers texte

Pour écrire du code C, vous devez éditer des fichiers. Vous avez plusieurs options :

Option 1 : Éditeur externe (recommandé pour débuter)

Utilisez un éditeur graphique comme gedit, Kate ou VS Code. Créez votre fichier avec touch, puis ouvrez-le depuis le gestionnaire de fichiers.

Option 2 : nano (simple et guidé)

nano est un éditeur de texte simple dans le terminal. Les commandes sont affichées en bas de l'écran :

╔══════════════════════════════════════════════════╗
║  GNU nano 7.2              test.c                ║
╠══════════════════════════════════════════════════╣
║                                                  ║
║  #include <stdio.h>                              ║
║                                                  ║
║  int main(){                                     ║
║      printf("Hello World\n");                    ║
║      return 0;                                   ║
║  }                                               ║
║                                                  ║
╠══════════════════════════════════════════════════╣
║ ^G Aide   ^O Écrire  ^W Chercher  ^K Couper     ║
║ ^X Quitter ^R Lire   ^\ Remplacer ^U Coller     ║
╚══════════════════════════════════════════════════╝

Commandes essentielles (le symbole ^ signifie Ctrl) :

  • Ouvrir un fichier : nano nomfichier.c
  • Sauvegarder : Ctrl+O puis Entrée
  • Quitter : Ctrl+X

Option 3 : vi/vim (pour les plus aventureux)

vi est un éditeur puissant mais avec une courbe d'apprentissage plus raide. Il fonctionne avec des modes :

  • Mode normal : déplacement et commandes (mode par défaut)
  • Mode insertion : écriture de texte (touche i)
  • Mode commande : commandes avancées (touche :)

Commandes de survie :

  • Ouvrir : vi nomfichier.c
  • Passer en mode insertion : i
  • Sortir du mode insertion : Échap
  • Sauvegarder et quitter : :wq puis Entrée
  • Quitter sans sauvegarder : :q! puis Entrée

Notre recommandation : Utilisez nano pour débuter. Une fois à l'aise avec Linux, vous pourrez explorer vim qui est très puissant pour l'édition de code.

5. Introduction à la compilation avec gcc

gcc (GNU Compiler Collection) est le compilateur C que nous utiliserons. Il transforme votre code source (.c) en programme exécutable.

5.1. Premier test avec un programme minimal

Dans le dossier INFO501/TD1, créez un fichier test.c :

nano test.c

Écrivez ce programme minimal :

int main(){
    return 0;
}

Sauvegardez (Ctrl+O) et quittez (Ctrl+X).

5.2. Compiler et exécuter

Compilez votre programme :

╔══════════════════════════════════════════════════╗
║  [user@fedora TD1]$ gcc test.c                   ║
║  [user@fedora TD1]$ ls                           ║
║  a.out  test.c                                   ║
║  [user@fedora TD1]$ █                            ║
╚══════════════════════════════════════════════════╝

Par défaut, gcc crée un fichier exécutable nommé a.out. Pour l'exécuter :

╔══════════════════════════════════════════════════╗
║  [user@fedora TD1]$ ./a.out                      ║
║  [user@fedora TD1]$ echo $?                      ║
║  0                                                ║
║  [user@fedora TD1]$ █                            ║
╚══════════════════════════════════════════════════╝

Le ./ signifie "dans le répertoire courant". La commande echo $? affiche le code de retour du programme (ici 0, ce qui signifie succès).

5.3. Donner un nom à l'exécutable

Pour donner un nom spécifique à votre programme, utilisez l'option -o :

╔══════════════════════════════════════════════════╗
║  [user@fedora TD1]$ gcc test.c -o mon_programme  ║
║  [user@fedora TD1]$ ls                           ║
║  mon_programme  test.c                           ║
║  [user@fedora TD1]$ ./mon_programme              ║
║  [user@fedora TD1]$ █                            ║
╚══════════════════════════════════════════════════╝

Exercice 1: Un triangle dans le terminal

On souhaite écrire un programme qui affiche un triangle dans le terminal. Pour cela, on vous demande d'écrire un programme qui prend en entrée un entier n impair et affiche un triangle de hauteur n dans le terminal. Par exemple, si n = 5, le programme devra afficher :

    *
   ***
  *****
 *******
*********
  1. Dans un premier temps, écrire un programme qui affiche un triangle de hauteur 3 pour vous familiariser avec printf.
  2. Supposez n fixé, écrire le programme.
    Aide

    Compter le nombre d'espaces à mettre et d'étoiles à mettre par ligne.

  3. Demandez à l'utilisateur de rentrer n et affichez le triangle correspond. Bonus: On pourra vérifiera que n est impair et redemander autant de fois que nécéssaire.
  4. Réorganiser votre code de façon à faire une fonction print_triangle qui prend en paramètre n et affiche le triangle correspondant. Le prototype de cette fonction sera void print_triangle(int n). On expliquera pourquoi on écrit void dans ce cas.

On s'organisera évidemment pour faire un autre dossier pour ce nouvel exercice de façon à ne pas mélanger les fichiers.

Exercice 2 : Des sommes et des produits

2.1 - Somme des \(n\) premiers entiers

On souhaite écrire un programme qui calcule la somme des \(n\) premiers entiers: $$ \sum_{i=1}^{n} i = 1 + 2 + 3 + \ldots + n. $$ Pour effectuer un calcul itératif de cette somme, supposons que nous ayons calculé la somme des \(n−1\) Premiers entiers et que nous ayons placé le résultat dans une variable resultat. On a alors que la somme des \(n\) premiers entiers est la somme des \(n−1\) premiers entiers plus \(n\).: $$ \underbrace{\sum_{i=1}^{n} i}_{\mathrm{resultat}} = \underbrace{\sum_{i=1}^{n-1} i}_{\mathrm{resultat}} + n $$ Ecrire un programme qui demande à l'utilisateur de rentrer un entier \(n\) et qui affiche la somme des \(n\) premiers entiers. On utilisera une boucle for pour effectuer la somme.

Aide

D'après la description, le pseudo-code serait le suivant:

resultat <- 0
pour i allant de 1 à n faire:
    resultat <- resultat + i
