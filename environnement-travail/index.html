Environnement de travail

Cette page décrit l'environnement informatique nécessaire sur vos ordinateurs personnels pour pouvoir réaliser les exercices en CM, les TDs et TPs du cours INFO501.

Outils nécessaires

Pour travailler en C dans ce cours, vous aurez besoin de trois éléments essentiels :

  • Un compilateur C (gcc) : transforme votre code source en programme exécutable
  • Un éditeur de code : nous recommandons Visual Studio Code pour sa simplicité et ses fonctionnalités
  • Un terminal : interface en ligne de commande pour compiler et exécuter vos programmes

Important : Dans ce cours, nous compilerons toujours manuellement via le terminal avec la commande gcc. Nous n'utiliserons pas les fonctionnalités de compilation automatique de VS Code. Cela vous permet de comprendre le processus de compilation et de maîtriser les options du compilateur.

🪟 Le cas Windows

Sous Windows, nous utiliserons WSL (Windows Subsystem for Linux), qui permet d'avoir un environnement Linux complet directement dans Windows. C'est la solution recommandée par Microsoft pour le développement.

1. Installation de WSL

Prérequis

Vous devez avoir Windows 10 version 2004 ou supérieure, ou Windows 11.

Étapes d'installation

  1. Ouvrez PowerShell en tant qu'administrateur (clic droit sur le menu Démarrer → "Terminal (admin)" ou "PowerShell (admin)")
  2. Exécutez la commande suivante :
wsl --install

Cette commande va :

  • Activer les fonctionnalités nécessaires de Windows
  • Télécharger et installer Ubuntu (la distribution Linux par défaut)
  • Installer WSL2 (la version la plus récente)
  1. Redémarrez votre ordinateur lorsque demandé
  2. Au redémarrage, une fenêtre Ubuntu s'ouvrira automatiquement. Patientez pendant l'installation finale
  3. Créez votre compte utilisateur Linux :
    • Entrez un nom d'utilisateur (en minuscules, sans espaces)
    • Entrez un mot de passe (il ne s'affichera pas pendant la saisie, c'est normal)
    • Confirmez le mot de passe

Note : Retenez bien votre mot de passe, vous en aurez besoin pour les commandes sudo (administrateur).

2. Installation de gcc

Une fois WSL installé, ouvrez le terminal Ubuntu et exécutez les commandes suivantes :

Mise à jour des paquets

sudo apt update && sudo apt upgrade -y

Entrez votre mot de passe lorsque demandé.

Installation des outils de développement

sudo apt install build-essential -y

Cette commande installe gcc, make et d'autres outils essentiels pour la compilation.

Vérification de l'installation

gcc --version

Vous devriez voir quelque chose comme :

╔══════════════════════════════════════════════════╗
║  gcc (Ubuntu 11.4.0-1ubuntu1~22.04) 11.4.0      ║
║  Copyright (C) 2021 Free Software Foundation...  ║
╚══════════════════════════════════════════════════╝

3. Installation de Visual Studio Code

  1. Téléchargez VS Code depuis le site officiel : https://code.visualstudio.com/
  2. Installez-le normalement sous Windows
  3. Ouvrez VS Code
  4. Installez l'extension "WSL" :
    • Cliquez sur l'icône Extensions dans la barre latérale (ou Ctrl+Shift+X)
    • Recherchez "WSL"
    • Installez l'extension officielle de Microsoft
  5. Installez l'extension "C/C++" :
    • Recherchez "C/C++"
    • Installez l'extension officielle de Microsoft

Ouvrir un dossier WSL dans VS Code

Pour travailler avec vos fichiers dans WSL :

  1. Ouvrez le terminal Ubuntu (WSL)
  2. Naviguez vers votre dossier de travail, par exemple : 
    mkdir -p ~/INFO501/TD1
cd ~/INFO501/TD1
  3. Ouvrez VS Code depuis ce dossier : 
    code .

VS Code s'ouvrira avec une connexion directe à WSL (vous verrez "WSL: Ubuntu" dans le coin inférieur gauche).

4. Test de l'environnement

Testons que tout fonctionne correctement :

  1. Dans VS Code connecté à WSL, créez un fichier test.c
  2. Écrivez ce programme : 
    #include <stdio.h>

int main(){
    printf("Hello depuis WSL!\n");
    return 0;
}
  3. Ouvrez le terminal intégré dans VS Code (Ctrl+` ou menu Terminal → New Terminal)
  4. Compilez : 
    gcc test.c -o test
  5. Exécutez : 
    ./test
  6. Vous devriez voir : 
    Hello depuis WSL!

Félicitations ! Votre environnement Windows est prêt pour programmer en C !

Informations complémentaires

Accéder aux fichiers WSL depuis Windows

Vous pouvez accéder à vos fichiers WSL depuis l'explorateur Windows en tapant dans la barre d'adresse :

\\wsl$\Ubuntu\home\votre_nom_utilisateur

Ou directement depuis l'explorateur de fichiers, WSL apparaît dans la barre latérale.

Problèmes courants
  • WSL ne démarre pas : Vérifiez que la virtualisation est activée dans le BIOS
  • "wsl --install" ne fonctionne pas : Vérifiez votre version de Windows avec winver
  • Permission denied lors de l'exécution : Vérifiez que vous avez bien compilé avec gcc et que le fichier existe

🍎 Le cas macOS

macOS est basé sur Unix, ce qui le rend naturellement adapté au développement en C. L'installation est simple grâce aux Command Line Tools fournis par Apple.

1. Installation des Command Line Tools

Les Command Line Tools incluent gcc (en réalité clang déguisé, mais compatible pour notre usage) et d'autres outils nécessaires.

Méthode simple

  1. Ouvrez le Terminal (Applications → Utilitaires → Terminal, ou cherchez "Terminal" avec Spotlight)
  2. Exécutez la commande : 
    xcode-select --install
  3. Une fenêtre apparaîtra, cliquez sur "Installer"
  4. Acceptez la licence et patientez pendant le téléchargement et l'installation (peut prendre quelques minutes)

Vérification de l'installation

Une fois l'installation terminée, vérifiez que tout fonctionne :

gcc --version

Vous devriez voir quelque chose comme :

╔══════════════════════════════════════════════════╗
║  Apple clang version 14.0.0 (clang-1400.0.29.2) ║
║  Target: arm64-apple-darwin22.1.0                ║
╚══════════════════════════════════════════════════╝

Note : Sur macOS, la commande gcc pointe en réalité vers clang, le compilateur C d'Apple. C'est tout à fait normal et suffisant pour ce cours. Les deux sont compatibles pour nos usages.

2. Installation de Visual Studio Code

  1. Téléchargez VS Code depuis le site officiel : https://code.visualstudio.com/
  2. Ouvrez le fichier .dmg téléchargé
  3. Glissez l'application VS Code dans le dossier Applications
  4. Lancez VS Code depuis le dossier Applications
  5. Installez l'extension "C/C++" :
    • Cliquez sur l'icône Extensions dans la barre latérale (ou Cmd+Shift+X)
    • Recherchez "C/C++"
    • Installez l'extension officielle de Microsoft

Ouvrir VS Code depuis le terminal (optionnel mais pratique)

Pour pouvoir lancer VS Code avec la commande code depuis le terminal :

  1. Ouvrez VS Code
  2. Ouvrez la palette de commandes (Cmd+Shift+P)
  3. Tapez "shell command" et sélectionnez "Shell Command: Install 'code' command in PATH"
  4. Redémarrez le terminal

Vous pourrez maintenant ouvrir des dossiers avec code . depuis le terminal.

3. Test de l'environnement

Testons que tout fonctionne correctement :

  1. Créez un dossier pour vos TDs : 
    mkdir -p ~/INFO501/TD1
cd ~/INFO501/TD1
  2. Ouvrez VS Code dans ce dossier : 
    code .
    Ou ouvrez VS Code et utilisez File → Open Folder
  3. Créez un fichier test.c avec ce contenu : 
    #include <stdio.h>

int main(){
    printf("Hello depuis macOS!\n");
    return 0;
}
  4. Ouvrez le terminal intégré dans VS Code (Ctrl+` ou menu Terminal → New Terminal)
  5. Compilez : 
    gcc test.c -o test
  6. Exécutez : 
    ./test
  7. Vous devriez voir : 
    Hello depuis macOS!

Parfait ! Votre environnement macOS est configuré et prêt à l'emploi !

Informations complémentaires

Installer le vrai gcc avec Homebrew (optionnel)

Si vous souhaitez vraiment utiliser GCC au lieu de Clang, vous pouvez l'installer via Homebrew :

  1. Installez Homebrew si ce n'est pas déjà fait : 
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  2. Installez gcc : 
    brew install gcc
  3. Utilisez gcc-13 (ou la version installée) au lieu de gcc

Note : Ce n'est pas nécessaire pour le cours. Clang est parfait pour nos besoins.

Problèmes courants
  • Les Command Line Tools ne s'installent pas : Vérifiez votre connexion internet et l'espace disque disponible (environ 2 Go nécessaires)
  • Permission denied lors de l'exécution : Vérifiez que vous avez bien compilé et que le fichier existe
  • xcrun: error: Réinstallez les Command Line Tools avec xcode-select --install

🐧 Le cas Linux

Linux est l'environnement natif idéal pour le développement en C. L'installation de gcc est simple et directe, selon votre distribution.

1. Installation de gcc

La méthode d'installation dépend de votre distribution Linux. Voici les commandes pour les distributions les plus courantes :

Debian / Ubuntu / Linux Mint

sudo apt update
sudo apt install build-essential -y

Fedora (comme à la fac)

sudo dnf install gcc gcc-c++ make -y

Arch Linux / Manjaro

sudo pacman -S base-devel

openSUSE

sudo zypper install gcc gcc-c++ make

Vérification de l'installation

Quelle que soit votre distribution, vérifiez que gcc est bien installé :

gcc --version

Vous devriez voir quelque chose comme :

╔══════════════════════════════════════════════════╗
║  gcc (GCC) 13.2.1 20230801                       ║
║  Copyright (C) 2023 Free Software Foundation...  ║
╚══════════════════════════════════════════════════╝

À la fac : Les machines de TP sous Fedora ont déjà gcc installé. Cette section est surtout pour votre ordinateur personnel.

2. Installation de Visual Studio Code

Il existe plusieurs méthodes pour installer VS Code sous Linux :

Méthode 1 : Paquet officiel (recommandé)

Pour Debian/Ubuntu :

  1. Téléchargez le paquet .deb depuis https://code.visualstudio.com/
  2. Installez-le : 
    sudo dpkg -i code_*.deb
sudo apt install -f

Pour Fedora :

  1. Téléchargez le paquet .rpm depuis https://code.visualstudio.com/
  2. Installez-le : 
    sudo dnf install code-*.rpm

Méthode 2 : Via Snap (toutes distributions)

sudo snap install code --classic

Méthode 3 : Via Flatpak (toutes distributions)

flatpak install flathub com.visualstudio.code

Installation de l'extension C/C++

  1. Lancez VS Code
  2. Ouvrez le panneau Extensions (Ctrl+Shift+X)
  3. Recherchez "C/C++"
  4. Installez l'extension officielle de Microsoft

3. Test de l'environnement

Testons que tout fonctionne correctement :

  1. Créez un dossier pour vos TDs : 
    mkdir -p ~/INFO501/TD1
cd ~/INFO501/TD1
  2. Ouvrez VS Code dans ce dossier : 
    code .
    Ou lancez VS Code et utilisez File → Open Folder
  3. Créez un fichier test.c avec ce contenu : 
    #include <stdio.h>

int main(){
    printf("Hello depuis Linux!\n");
    return 0;
}
  4. Ouvrez le terminal intégré dans VS Code (Ctrl+` ou menu Terminal → New Terminal)
  5. Compilez : 
    gcc test.c -o test
  6. Exécutez : 
    ./test
  7. Vous devriez voir : 
    Hello depuis Linux!

Excellent ! Votre environnement Linux est prêt. Vous disposez de l'environnement natif idéal pour le développement C !

Informations complémentaires

Installer VS Code via le dépôt officiel Microsoft

Pour recevoir les mises à jour automatiques via votre gestionnaire de paquets :

Debian/Ubuntu :

wget -qO- https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > packages.microsoft.gpg
sudo install -D -o root -g root -m 644 packages.microsoft.gpg /etc/apt/keyrings/packages.microsoft.gpg
sudo sh -c 'echo "deb [arch=amd64,arm64,armhf signed-by=/etc/apt/keyrings/packages.microsoft.gpg] https://packages.microsoft.com/repos/code stable main" > /etc/apt/sources.list.d/vscode.list'
sudo apt update
sudo apt install code

Fedora/RHEL :

sudo rpm --import https://packages.microsoft.com/keys/microsoft.asc
sudo sh -c 'echo -e "[code]\nname=Visual Studio Code\nbaseurl=https://packages.microsoft.com/yumrepos/vscode\nenabled=1\ngpgcheck=1\ngpgkey=https://packages.microsoft.com/keys/microsoft.asc" > /etc/yum.repos.d/vscode.repo'
sudo dnf check-update
sudo dnf install code
Problèmes courants
  • gcc: command not found : gcc n'est pas installé, réexécutez la commande d'installation pour votre distribution
  • Permission denied lors de l'exécution : Vérifiez que vous avez bien compilé et que le fichier existe
  • Erreur avec sudo : Assurez-vous que votre utilisateur a les droits sudo
  • VS Code ne se lance pas avec Snap : Essayez la méthode via paquet .deb ou .rpm

⚙️ Configuration de VS Code (tous systèmes)

Maintenant que VS Code est installé sur votre système, voici quelques configurations et extensions utiles pour travailler efficacement en C.

Extensions recommandées

Extensions essentielles

  • C/C++ (Microsoft) - Obligatoire
    • Coloration syntaxique
    • IntelliSense (autocomplétion)
    • Détection d'erreurs de syntaxe

Extensions optionnelles mais utiles

  • C/C++ Extension Pack (Microsoft) - Pack complet d'outils C/C++
  • Error Lens - Affiche les erreurs directement dans le code
  • Better C++ Syntax - Meilleure coloration syntaxique
  • Code Spell Checker - Vérification orthographique dans les commentaires

Configuration du terminal intégré

VS Code dispose d'un terminal intégré très pratique pour compiler sans quitter l'éditeur :

  • Ouvrir/Fermer le terminal : Ctrl+` (ou Cmd+` sur macOS)
  • Créer un nouveau terminal : Cliquez sur le + dans le panneau terminal
  • Basculer entre terminaux : Menu déroulant dans le panneau terminal

Rappel important : Nous compilerons toujours manuellement en tapant gcc dans le terminal. Ne cherchez pas de bouton "Compiler" ou "Run" dans VS Code. Le but est de comprendre le processus de compilation, pas de l'automatiser.

Raccourcis clavier utiles

Action Windows/Linux macOS
Ouvrir le terminal Ctrl+` Cmd+`
Sauvegarder Ctrl+S Cmd+S
Sauvegarder tout Ctrl+K S Cmd+K S
Ouvrir un fichier Ctrl+O Cmd+O
Rechercher dans le fichier Ctrl+F Cmd+F
Palette de commandes Ctrl+Shift+P Cmd+Shift+P

Personnalisation (optionnel)

Ajuster la taille de la police
  1. Fichier → Préférences → Paramètres (ou Ctrl+,)
  2. Recherchez "Font Size"
  3. Ajustez selon vos préférences (12-16 recommandé)
Changer le thème
  1. Fichier → Préférences → Thème de couleur
  2. Choisissez un thème sombre ou clair selon votre préférence
  3. Thèmes populaires : Dark+ (par défaut), Light+, Monokai, Solarized

📋 Workflow de travail et récapitulatif

Le cycle de développement en C

Voici le workflow que vous utiliserez tout au long du cours :

  1. Éditer : Écrivez ou modifiez votre code dans VS Code
    • Profitez de la coloration syntaxique
    • L'autocomplétion vous aidera
    • Les erreurs de syntaxe évidentes seront soulignées
  2. Sauvegarder : Ctrl+S (ou Cmd+S)
  3. Compiler : Dans le terminal, tapez : 
    gcc nomfichier.c -o nomprogramme
    • Si erreurs de compilation : lisez les messages, corrigez et recompilez
    • Si succès : un fichier exécutable est créé
  4. Exécuter : Dans le terminal : 
    ./nomprogramme
  5. Tester : Vérifiez que le programme fait ce qui est attendu
  6. Débugger : Si le résultat n'est pas correct, retour à l'étape 1

Checklist de vérification de l'environnement

✓ Vérifiez que vous avez :

  • ☐ gcc --version fonctionne et affiche une version
  • ☐ VS Code est installé et se lance
  • ☐ L'extension C/C++ est installée dans VS Code
  • ☐ Le terminal s'ouvre correctement (intégré dans VS Code ou externe)
  • ☐ Vous avez réussi à compiler et exécuter le programme de test
  • ☐ Vous savez ouvrir un dossier dans VS Code
  • ☐ Vous savez créer un nouveau fichier

Commandes essentielles à retenir

Commande Description
gcc fichier.c Compile et crée a.out
gcc fichier.c -o nom Compile avec nom personnalisé
gcc -Wall fichier.c Compile avec tous les avertissements
gcc -Wextra fichier.c Avertissements supplémentaires
./programme Exécute le programme compilé
ls Liste les fichiers du dossier
pwd Affiche le dossier courant
cd dossier Change de dossier

Bonnes pratiques

  • Organisation : Créez un dossier par TD/TP (ex: ~/INFO501/TD1/, ~/INFO501/TD2/)
  • Nommage : Utilisez des noms explicites pour vos fichiers (exercice1.c, triangle.c)
  • Sauvegarde : Sauvegardez régulièrement votre travail
  • Compilation : Compilez souvent pour détecter les erreurs tôt
  • Avertissements : Utilisez -Wall -Wextra pour détecter plus de problèmes potentiels
  • Tests : Testez votre code avec différentes entrées
